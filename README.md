# 家計簿 Web MVP v15

現在のバージョン：**v15**

v14の不具合を修正し、支出一覧とグラフが正常に表示・更新されるようにしました。

## v15の変更点
- `app.js` が存在しない画面要素を参照して処理が停止する不具合を修正
- 「今月の支出」が正常に表示されるよう修正
- カテゴリ別・日別・月別・貯金額のグラフが正常に表示されるよう修正
- 支出追加・編集・削除後にグラフと支出一覧を正常に更新
- 支出の▲▼ボタンは、画面上の表示順に合わせて動作するよう修正
- ▲▼は同じ日付の支出の中だけで順番を入れ替える仕様を維持
- アプリ本体のバージョン表示をv15に更新

## 主な機能
- 支出の記録・編集・削除
- 同じ日付内の支出順変更（▲▼）
- 固定費・貯金を先に確保する家計ルール
- 超過収入のお小遣い・貯金への自動振り分け
- 1日あたりの使用目安
- 使いすぎ判定・月末予測
- カテゴリ別、日別、月別の支出グラフ
- 月別の貯金額グラフ
