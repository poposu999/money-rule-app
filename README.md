# 家計簿 Web MVP ver.20

現在のバージョン：**ver.20**

## ver.20の変更点
- 各項目の「−」ボタンによる非表示・再表示を修正
- 今月の支出を「1日 → 31日」の昇順に変更
- 今月の支出一覧の行間・文字・操作ボタンをコンパクト化
- 支出表示処理のJavaScriptエラーを修正し、支出一覧・グラフ・各種表示が連鎖的に停止しないよう修正
- 「今月の状況」を白枠のひとつのセクションとして整理
  - 「今月の残り予算」の右に残り日数を表示
  - 「1日あたりの目安」の右に計算式を表示
  - 残り予算などの各項目の囲い方・余白を整理
- 「今月の状況」の収入表示を「前月の収入」に変更
- 「使いすぎ予測」で予算オーバー見込みの場合、残り日数に応じた1日あたりの抑制目安を表示
  - ブラウザキャッシュ対策のバージョン番号を更新
