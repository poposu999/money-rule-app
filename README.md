# 家計簿 Web MVP ver.24

現在のバージョン：**ver.24**

## ver.24の変更点
- 「今月の状況」の並び順を、今月使った金額 → 今月の残り予算 → 1日あたりの目安 → 前月の収入 → 毎月の最低限の手取りからの超過分 → 今月の貯金予定 → 今月使える予算、に変更
- 「今月の支出件数」を削除
- 「今月のお小遣い枠」を削除
- 「前月の収入」の非表示ボタンを、マイナス記号が分かりやすいボタン表示に調整
