# 家計簿 Web MVP ver.30

現在のバージョン：**ver.30**

## ver.30の変更点
- 今月の総支出予算を「総収入 − 通常の貯金目標 − 超過分の貯金」で計算するよう修正
- 固定費を今月の総支出予算から直接差し引かないよう修正
- 支出一覧の日付表示を `MM/DD` に変更
- 支出一覧の編集・削除ボタンを右寄せに調整
- 支出一覧のメモ表示欄を広く調整
- 支出一覧の▲▼操作を一覧から削除し、編集画面から同じ日付内の順番を変更できるよう追加
- 金額欄で `1200+300` のような四則演算を入力できるよう追加
- 支出入力のカテゴリ・メモ・日付を前回値から引き継ぐよう追加
- 入力チェックは問題がない場合は表示せず、矛盾がある場合だけ表示するよう変更
- 「使いすぎ予測」の詳細表示を削除
- 毎月の固定費を登録できるよう追加
- 登録した固定費を当月の予定支出へ自動登録し、支払ったら「支出に確定」で実績へ移せるよう追加
- 固定費を登録・削除すると、家計ルールの固定費合計にも自動反映するよう変更
- スマートフォンで日付入力欄がはみ出しにくいよう調整
