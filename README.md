# 家計ルール Web MVP
index.htmlをChrome/Edgeで開けば動きます。

## できること
- 最低限の手取り・固定費・貯金目標を設定
- 超過収入をお小遣い/貯金に配分
- 今月の収入をブラウザ内に保存
- 支出を記録
- 今日の支出、今月の支出、残り予算、1日あたり目安を自動計算
- データはブラウザのlocalStorageに保存

## 計算
超過収入 = max(0, 収入 - 最低限の手取り)
追加お小遣い = 超過収入 × お小遣い割合
追加貯金 = 超過収入 × 貯金割合
貯金予定 = 毎月の貯金目標 + 追加貯金
使える予算 = 収入 - 固定費 - 毎月の貯金目標 + 追加お小遣い
残り予算 = 使える予算 - 変動支出
