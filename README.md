# 家計簿 Web MVP ver.40

現在のバージョン：**ver.40**

## ver.40の変更点
- 「支出を入力」の日付を、ページを開いたとき・リロードしたときは当日にリセットするよう変更
- ページを開いたまま連続して支出を登録する場合は、直前に登録した日付とカテゴリを引き継ぐよう変更
- 支出を登録するたびに金額とメモは空欄へリセットするよう変更
- 既存の家計簿データを初期化せずに読み込むよう、ver.38をベースに更新
