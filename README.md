- 支出記録のメモを前回入力から記憶しないよう変更
- 固定費の「支出に確定」ボタンを「今月の予定支出」と同じサイズに調整
- 「今月の状況」の前月収入の表示切替を枠の最下部のボタンに変更
- 「今月の状況」の項目順を変更
- 「使いすぎ予報」を追加し、現在の支出ペースから月末の支出額を予測するよう変更
