# 家計簿 ver.49

## ver.49の変更点
- 月切り替え、過去・未来月の収入・支出・家計ルールの管理に対応。
- 固定費の変更履歴、予定支出の確定・戻す操作、月またぎ編集に対応。
- カテゴリ別・日別・月別グラフとスマートフォンの表示を調整。
- 編集ボタンとアプリ内の確認・通知画面を統一。
- 月別データのバックアップ・復元、データ整合性チェックを追加。
- 本番ver.48の保存データをver.49へ移行。移行前にバックアップを保存し、移行後も旧データを保持。

## 初回起動
本番アプリで「先にバックアップを保存」後、「移行を開始」を押してください。
旧版の収入・ボーナス・家計ルールは移行した月に引き継ぎます。支出・予定支出は各日付の月に表示され、固定費設定は移行した月から有効です。
検証環境の保存データは読み込みません。
