# 家計簿 Web MVP ver.42

現在のバージョン：**ver.42**

## ver.42の変更点
- 固定費と予定支出の入力内容を直前の入力から記憶しないよう変更
- 固定費と予定支出のカテゴリをワンタップで選択できるボタンを追加
- 「支出ペース・使いすぎ予報」を一番上に移動
- 「今月の支出」「今月の予定支出」「固定費一覧」の並び順を変更
- タイトルと説明文をページの一番下へ移動
- グラフの再描画処理を整理し、入力後も表示を更新するよう調整

## データ
家計簿データはブラウザのlocalStorageに保存されます。


## ver.42の変更点
- ver.37の機能構成を基準に再構成
- ver.37で欠落していた支出・予定支出・固定費の編集モーダルを復元
- 支出入力は、ページを開いた直後は日付を今日にする
- 連続登録では直前に登録した日付とカテゴリを維持する
- 支出の金額とメモは登録ごとに空欄へ戻す
- 日付は入力記憶として保存せず、カテゴリのみ保存する
- 既存のlocalStorageキー `moneyRuleAppV2` は変更しない
