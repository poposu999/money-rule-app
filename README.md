# 家計簿 Web MVP ver.30

現在のバージョン：**ver.30**

## ver.30の変更点
- スマートフォン表示で「支出を記録」の日付入力欄がはみ出しにくいよう調整
- 「今月の支出」の日付表示を `YYYY/MM/DD` から `MM/DD` に変更
- 支出の並び替え操作を整理し、編集時に行えるように調整
- 今月の予算を「収入 − 通常の貯金目標 − 超過分の貯金」で計算する形に変更
- 固定費は今月の予算から直接差し引かず、「今月の予定支出」として扱う形に整理
- 金額入力で簡単な四則演算を使えるように変更
- 予算計算に関係する入力値のチェック情報を追加
