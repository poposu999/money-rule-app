# 家計簿 Web MVP ver.27

## ver.27の変更点
- 「今月の予定支出」を追加し、今月中に使う予定のお金を事前登録できるように変更
- 予定支出を「今月の残り予算」に自動反映するように変更
- 予定支出を「支出に確定」で実際の支出へ移せるように変更
- 予定支出の編集・削除に対応
- 支出カテゴリに「美容」「医療関係」を追加
- 「水光熱費」「美容」「医療関係」をカテゴリ別集計・入力欄に反映
- アプリ画面のバージョン表記を **ver.27** に更新
