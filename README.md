# 家計簿 ver.50.2

本番版です。初回移行前にバックアップファイルの保存確認が必要です。

## この版の変更点

- ホーム・年間レポート・収入と家計ルール・データ管理をメニューから切り替えられます。記録ボタンは右下に固定表示します。
- 年間明細の検索・カテゴリ絞り込み・編集、月平均表示に対応します。
- 予定支出と固定費の支払済み行を残し、実支出と連携します。固定費の月別変更、継続変更、支払いなしに対応します。
- 編集画面の入力・並び順・支払い状態は保存まで仮変更となり、キャンセル・×・背景タップで破棄します。
- 実支出と未払い予定額を分離して予算・グラフを集計します。整合性チェックとバックアップ確認を伴う手動修復を追加します。
- 初回移行はバックアップファイルの保存確認後に行います。旧本番データを残し、本番専用の新保存領域へ検証して切り替えます。
- 本番のver.48・49形式バックアップを復元できます。検証用バックアップは拒否します。
- 本番用オフライン対応を維持します。利用にはオンラインでの更新完了が必要です。

## 環境とデータ

本番専用保存領域は `moneyRuleV50:*`、旧本番の `moneyRuleAppV49`・`moneyRuleAppV2` は保持します。検証環境の保存領域からコピー・同期しません。保存形式はschemaVersion 50です。


## バックアップ通知（Issue #3）

データ管理で通知をONにすると、7・30・90日の間隔でホームに通知します。初期状態はOFF、OFF→ON時は30日です。「今日は閉じる」を押した日だけ通知を抑制します。

最終バックアップ日時は「保存できました」の確認後に、そのJSONのexportedAtを記録します。復元時は正常かつ未来でないexportedAtのみ採用し、それ以外は記録なしとします。通知ON/OFF・間隔・当日の抑制は復元で巻き戻りません。

通知情報は家計データと別の本番専用キー `moneyRuleBackupReminder` に保存します。検証用 `moneyRuleDevBackupReminder` と分離し、通常の家計簿バックアップには含めません。Web Push・自動バックアップは行いません。
