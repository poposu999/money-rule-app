# 家計簿 Web MVP v4

ブラウザだけで動く家計簿アプリです。

## v4で追加
- 支出入力をページ上部に配置
- 予算に対する支出進捗バー
- カテゴリ別支出グラフ
- 日ごとの支出推移グラフ
- 月別の支出推移グラフ
- 月別の貯金予定グラフ
- 支出の削除機能
- 支出件数表示

## データ
入力データはブラウザの localStorage に保存されます。
別の端末・ブラウザとは同期されません。

## GitHub Pages
`index.html`、`style.css`、`app.js`、`README.md` をリポジトリのルートにアップロードしてください。
