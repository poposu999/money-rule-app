# 家計簿 Web MVP ver.31

現在のバージョン：**ver.31**

## ver.31の変更点
- 「お金の内訳」を削除
- 「使いすぎ予測」を削除
- 入力チェックは問題がない場合は表示せず、エラーがある場合だけ表示するよう変更
- 「今月の支出」の編集・削除ボタンを右寄せに変更
- 支出一覧のメモ表示欄を広く変更
- 「固定費を登録」を追加し、固定費を独立した一覧で管理できるよう変更
- 固定費は「今月の予定支出」には反映せず、固定費一覧の中だけで管理するよう変更
- 固定費に「支出に確定」「編集」「削除」を追加
- 固定費を支出に確定すると、今月の支出として記録されるよう変更
