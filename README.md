# 家計簿 Web MVP ver.41

現在のバージョン：**ver.41**

## ver.41の変更点
- 支出入力の日付はページを開いたとき・リロード時に当日へ戻し、同じページで連続登録すると直前の日付を引き継ぐよう変更
- 支出入力ではカテゴリも連続登録時に引き継ぎ、金額とメモは登録後に空欄へ戻すよう変更
- 既存の家計簿データを初期化せず、従来と同じ保存領域を引き継ぐ構成で更新
