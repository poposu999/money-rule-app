# 家計簿 Web MVP ver.29

現在のバージョン：**ver.29**

## ver.29の変更点
- ブラウザを変更するときに家計簿データを移動できる「データのバックアップ」機能を追加
- 家計簿データをJSONファイルとして書き出せるように変更
- JSONバックアップを新しいブラウザから読み込めるように変更
- 読み込み時は現在の家計簿データをバックアップ内容へ置き換える確認を表示

## ファイル
- `index.html`
- `style.css`
- `app.js`
- `README.md`

## データ
家計簿データはブラウザのlocalStorageに保存されます。
